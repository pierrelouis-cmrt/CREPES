# Côtes

Ces fichiers forment un shapefile Natural Earth de lignes de côte. Ils sont lus par `visualisation_commune.py` pour les contours des cartes et globes.

Conserver ensemble `ne_10m_coastline.shp`, `.shx`, `.dbf` et `.prj`. Si ce shapefile ou `pyshp` manque, les visualisations fonctionnent encore mais sans contours. Ces fichiers n'interviennent pas dans le calcul thermique et ne sont pas générés par le projet.
