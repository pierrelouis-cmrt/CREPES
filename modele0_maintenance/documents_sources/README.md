# Documents sources

Ce dossier conserve les PDF reçus des groupes à l'origine du modèle 0. Ils sont des documents de référence et ne sont ni lus ni modifiés par les scripts.

| Document | Utilité dans la maintenance |
| --- | --- |
| `Carcajous_Synthese.pdf` | Socle du moteur de surface et de ses données. |
| `Chevreaux_Docu_de_synthese.pdf` | Contexte de la convection forcée. |
| `Chevreaux_Modele_6.pdf` | Détails complémentaires du groupe Chevreaux. |
| `Chevreaux_Modele_evapotranspiration.pdf` | Documentation de l'évapotranspiration conservée. |
| `Bernard_Synthese.pdf` | Origine de l'interface carte vers courbe. |
| `Ornithorynquietant_Synthese.pdf` | Convection naturelle, diffusion et viewer mensuel. |

La correspondance entre ces apports et le code maintenu est consignée dans [`../PROVENANCE.md`](../PROVENANCE.md). Les documents théoriques du modèle sont conservés au niveau du dossier `modele0_maintenance/`.
