# Tests — modèle 5

Ce dossier vérifie la conservation des échanges entre interfaces, le cas de
température uniforme, une simulation courte et l'écriture du résultat `.npz`.

## Lancer

Depuis la racine du dépôt :

```bash
python modele5/tests/tester_modele5.py
```

## Structure

| Fichier | Rôle |
| --- | --- |
| `tester_modele5.py` | Exécute les tests du moteur et des échanges horizontaux. |

Le moteur testé est décrit dans le [README parent](../README.md).
