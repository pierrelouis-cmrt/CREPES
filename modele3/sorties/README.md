# Sorties — modèle 3

Ce dossier conserve les figures et diagnostics exportés pendant le travail sur
le modèle 3. Ils ne sont pas lus par `modele3.py`.

## Structure

| Élément | Rôle |
| --- | --- |
| `absorbance_h2o.png` | Export du graphique indicatif de l'absorption de la vapeur d'eau. |

La figure H₂O est liée au script
[`../ressources/Absorbance_H2O.py`](../ressources/Absorbance_H2O.py). Elle
est illustrative : le runtime utilise des coefficients d'opacité chargés depuis
`../ressources/`, et non cette image.
