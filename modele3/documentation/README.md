# Documentation — modèle 3

Ce dossier rassemble les documents de référence du modèle 3 ; aucun script ne
s'y exécute directement.

## Structure

| Fichier | Contenu |
| --- | --- |
| `THEORIE.md` | Hypothèses, équations et limites du calcul radiatif. |
| `CALIBRAGE_CO2_H2O.md` | Rappel méthodologique dense du calibrage HITRAN/RADIS des coefficients CO₂ et H₂O. |
| `CALIBRAGE_H2O.md` | Méthode proposée de calibrage HITRAN/RADIS des coefficients H₂O. |
| `PROVENANCE_DONNEES.md` | Sources, transformations et traçabilité des données. |
| `recap_ERA5.md` | Inventaire des données ERA5 mobilisées. |
| `RECHERCHE_SHORTWAVE_ET_OPTIMISATION.md` | Notes sur le court-onde et les optimisations. |

La visualisation qualitative H₂O du dossier `ressources/` est distinguée du
calibrage scientifique : elle est décrite dans le
[README des ressources](../ressources/README.md).

Pour lancer le modèle, voir le [README parent](../README.md).
