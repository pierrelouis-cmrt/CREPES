# Visualisation — modèle 4

Ce dossier est réservé aux outils de visualisation du modèle 4. La
visualisation active des sorties `.npz` est mutualisée à la racine du dépôt.

## Lancer

Depuis la racine du dépôt :

```bash
python planisphere.py
```

Sans argument, le script propose les sorties présentes dans `modele4/sorties/`
et `modele5/sorties/`.
